# Vrinda-Store-Sales-Analysis.
Excel Dashboard and Data Analysis for Vrinda Store retail sales
## Project Overview
This project provides a comprehensive analysis of **Vrinda Store's** sales data for the year 2022. The goal was to transform raw data into actionable insights to help the store improve its sales strategy.

### Key Features:
* **Data Cleaning:** Handled null values and standardized columns (Gender, Age, State).
* **Data Processing:** Created new columns for age groups (Teen, Adult, Senior).
* **Interactive Dashboard:** Built using Pivot Tables and Slicers for dynamic filtering.

### Key Insights (Optional):
* **Women** are the primary customers, contributing to ~65% of total sales.
* **Maharashtra, Karnataka, and Uttar Pradesh** are the top 3 performing states.
* **Amazon and Flipkart** are the most effective sales channels.

### Tools Used:
* Microsoft Excel (Pivot Tables, VLOOKUP, Data Visualization)
